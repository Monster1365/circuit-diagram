# circuit-diagram (CD)

브라우저에서 논리회로를 그리고 바로 동작을 확인할 수 있는 웹 도구입니다.
회로 계산은 모두 사용자의 브라우저에서 실행되며, 서버로 회로 데이터를 보내지 않습니다.

## 부품

| 분류 | 부품 | 설명 |
|---|---|---|
| 입출력 | 전원 | 신호 1을 내보냅니다. 클릭해서 켜고 끕니다. |
| | 클럭 | 주기마다 0과 1을 번갈아 내보냅니다. `−` / `+` 버튼으로 주기(100ms ~ 5s)를 바꿉니다. |
| | 스위치 | 닫혀 있을 때만 입력 신호를 통과시킵니다. 클릭해서 열고 닫습니다. |
| | LED | 입력이 1이면 켜집니다. |
| 논리 게이트 | AND · OR · NOT · NAND · NOR · XOR · XNOR | 표준 논리 게이트입니다. 연결되지 않은 입력은 0으로 계산합니다. |

## 사용법

### 부품 놓기와 연결
- 왼쪽 도구상자에서 부품을 **캔버스로 끌어다 놓거나 클릭**해서 추가합니다. (클릭하면 화면 가운데에 놓입니다)
- 부품의 연결점(●)에 마우스를 올리고 끌면 선이 생깁니다. 출력 → 입력 방향으로만 연결되고, 입력 하나에는 선 하나만 연결됩니다.
- **선 없이 연결점끼리 겹쳐 놓아도 연결됩니다.** 한 부품의 출력점과 다른 부품의 입력점이 같은 자리에 있으면 연결된 것으로 계산하고, 겹쳐 연결된 점은 채운 점(●)으로 표시합니다. 그 입력에 선이 따로 연결되어 있으면 선이 우선합니다.
- 모든 부품의 크기와 연결점은 격자 한 칸(20px)에 맞춰져 있어, 같은 높이의 연결점끼리는 선이 일자로 이어집니다.
- 신호가 1인 선은 초록색, 0인 선은 회색으로 표시됩니다.

### 화면 조작

| 동작 | 방법 |
|---|---|
| 화면 이동 | 터치패드 두 손가락 드래그 / 마우스 휠 / 마우스 가운데 버튼 드래그 |
| 확대·축소 | 터치패드 핀치 / `Ctrl`(Mac은 `⌘`) + 휠 / 왼쪽 아래 `+` `−` 버튼 |
| 여러 부품 선택 | 배경을 끌어 선택 상자 그리기 / `Shift` + 클릭 |
| 선택한 부품 이동 | 선택한 부품 중 하나를 끌기 |

부품을 선택하면 캔버스 위쪽에 **선택 도구 모음**이 나타납니다. 여기서 크기 배율(×1 ~ ×4), 그룹 묶기/풀기, 삭제를 할 수 있습니다.
여러 부품을 함께 키우거나 줄이면 부품 사이 거리도 같은 비율로 바뀝니다.

### 단축키

Mac에서는 `Ctrl` 대신 `⌘`를 사용합니다.

| 단축키 | 동작 |
|---|---|
| `Ctrl` + `C` / `X` / `V` | 복사 / 잘라내기 / 붙여넣기 (부품 사이의 선도 함께) |
| `Ctrl` + `D` | 선택한 부품 복제 |
| `Ctrl` + `A` | 전체 선택 |
| `Ctrl` + `Z` | 되돌리기 (최대 100단계) |
| `Ctrl` + `Shift` + `Z`, `Ctrl` + `Y` | 다시 실행 |
| `Ctrl` + `G` | 선택한 부품을 그룹으로 묶기 / 그룹 전체가 선택된 상태에서 누르면 풀기 |
| `Delete`, `Backspace` | 선택한 부품·선 삭제 |

### 그룹
- 그룹으로 묶은 부품은 함께 선택되고 함께 움직입니다.
- 그룹끼리 다시 묶으면 **그룹 안에 그룹**이 들어갑니다. (예: 그룹 1과 그룹 2를 묶으면 그룹 3이 되고, 그룹 3을 풀면 그룹 1과 그룹 2로 돌아옵니다)
- 도구상자 아래 **배치된 부품** 목록에서 그룹을 접거나 펼칠 수 있고, 항목을 누르면 그 부품이 선택되며 화면이 그 위치로 이동합니다.

### 화면 구성
- **도구상자**(왼쪽): 위쪽은 부품 버튼, 아래쪽은 배치된 부품 목록입니다. 상단 왼쪽 버튼으로 열고 닫고, 가장자리를 끌어 넓이를 바꿉니다(180 ~ 420px).
- **로그**(오른쪽): 상단의 `로그 보기`로 엽니다. 지금 켜진 LED 목록과 클럭 신호 그래프를 보여줍니다. 넓이 조절은 도구상자와 같습니다.
- **설정**(오른쪽 위 톱니바퀴): 그룹 점선 표시 켜기/끄기, LED 색(빨·주·노·초·파·남·보)을 고릅니다. 설정은 브라우저에 저장됩니다.

